# Taskflow

A clean, responsive task manager built with vanilla HTML, CSS, and JavaScript. Tasks and projects persist in the browser using local storage—no backend or setup required.

## Features

- Create, edit, complete, and filter tasks
- Organize work with projects and priorities
- Today, upcoming, and completed views
- A live task summary and daily-focus indicator
- Responsive mobile layout and optional dark mode
- Browser-based persistence via local storage

## Run locally

Open `index.html` in a browser, or serve the folder with any static-file server.

## Deploy to Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. In Vercel, select **Add New → Project** and import that repository.
3. Leave the build settings blank (this is a static site), then select **Deploy**.

The included `vercel.json` is already configured for deployment.
